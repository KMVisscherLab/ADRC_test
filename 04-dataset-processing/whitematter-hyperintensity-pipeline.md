## Component Overview

This component documents the complete white matter hyperintensity (WMH) processing workflow used for the ADRC cohort. It is in the folllowing Box folder address:

https://uab.app.box.com/folder/404648375268

The workflow prepares T1-weighted and T2-FLAIR MRI data, optionally applies optimized Non-Local Means denoising to T2-FLAIR images, performs FLAIR-assisted T1 preparation for pial correction, runs FreeSurfer, processes lesion-probability maps generated by the MATLAB LST-LPA pipeline, classifies WMH lesions, calculates lesion volumes, compiles cohort-level results, and optionally converts the final WMH label map into a DICOM series for local review.

The purpose of this documentation is to allow a future user to understand, reproduce, quality-control, troubleshoot, and maintain the workflow without depending on verbal instructions from the original developer.

> **Important:** This component should remain private unless the principal investigators and UAB approve public sharing. Do not upload identifiable images, DICOM headers containing protected health information, passwords, tokens, or restricted participant-level data to OSF.

## 1. Workflow Summary

The complete workflow is:

```text
T1 and T2-FLAIR DICOM
        |
        v
Select correct T1 and FLAIR series
        |
        v
Convert DICOM to NIfTI
        |
        +------------------------------+
        |                              |
        v                              v
Use original T2-FLAIR          Apply optional optimized
without denoising              NLM denoising to T2-FLAIR
        |                              |
        +---------------+--------------+
                        |
                        v
Record whether the subject was processed
with or without denoising
                        |
                        v
Register FLAIR to T1
                        |
                        v
Create FLAIR-assisted T1 image for pial correction
                        |
                        v
Run FreeSurfer
                        |
                        v
Copy FreeSurfer outputs into each subject folder
                        |
                        v
Transform FreeSurfer segmentation, brain mask, and T1
into native FLAIR space
                        |
                        v
Run MATLAB LST-LPA
                        |
                        v
Standardize LST-LPA output names and folders
                        |
                        v
Threshold lesion-probability map at 0.36
                        |
                        v
Create binary WMH mask in FreeSurfer space
                        |
                        v
Group and classify lesions relative to the ventricles
                        |
                        v
Calculate AV-WMH, D-WMH, PV-WMH, and total white-matter volumes
                        |
                        v
Compile cohort-level CSV
                        |
                        v
Select maximum, minimum, and median cases for QC
                        |
                        v
Optionally transform the label map back to native FLAIR space
and export it as a derived DICOM series
```

### Tested Computing Environment

The workflow has been run and operationally tested on the UAB Cheaha high-performance computing environment. Cheaha was used for batch processing, Slurm job submission, FreeSurfer execution, and cohort-level processing.

Operational testing on Cheaha confirms that the documented workflow can execute in that environment. It does not by itself establish scientific validation of every processing choice or guarantee identical results on a different operating system, software version, scanner, or acquisition protocol.

### Adaptation to a Local PC or Workstation

The workflow can be adapted for use on a local workstation that has MATLAB and Python. The Python code, MATLAB LST-LPA steps, directory paths, and batch-processing logic must be changed from Cheaha-specific commands to local paths and local execution.

A complete local installation may also require:

- FreeSurfer and its command-line utilities
- A Linux-compatible shell environment
- SPM and LST-LPA in MATLAB
- The required Python packages
- Sufficient memory, storage, and processing time
- Access to the external WMH scripts used by the notebook

On a Windows PC, FreeSurfer and shell-based steps may require Windows Subsystem for Linux, a Linux virtual machine, a container, or execution on a separate Linux server. Therefore, MATLAB and Python are the minimum requirements for adapting the workflow, but they may not be the only software required for the complete pipeline.

### Optional Processing Branches

The pipeline supports two analysis branches:

1. **Without denoising:** The original converted T2-FLAIR image is used.
2. **With denoising:** The T2-FLAIR image is processed with the optimized Non-Local Means method before downstream WMH processing.

The selected branch must be recorded for every subject and reflected in the output folder, output filename, processing log, and cohort-level results. Results generated with and without denoising should not be mixed without an explicit analysis plan.
