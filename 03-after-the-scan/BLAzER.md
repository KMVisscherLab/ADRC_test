The BLAzER workflow is a process for semi-automated image analysis, called Biomarker Localization, Analysis, Visualization, Extraction, and Registration (BLAzER), which we use to harmonize the PET and MRI data for these projects. You can read published descriptions of the workflow here: https://www.researchgate.net/publication/334501687_Biomarker_Localization_Analysis_Visualization_Extraction_and_Registration_BLAzER_Methodology_for_Research_and_Clinical_Brain_PET_Applications 

The complete workflow documentation for the ADRC use of this workflow—including the Blazer process using MIM for ADRC Consensus Conferences, FreeSurfer processing, and SUVR extraction—is available in the following Box folder:

https://uab.app.box.com/file/2293900374288
